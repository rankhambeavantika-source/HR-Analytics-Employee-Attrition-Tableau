# HR Analytics – Employee Attrition Analysis | Tableau

## 📌 Project Overview

This project presents an interactive HR Analytics dashboard built using Tableau to analyze employee attrition, workforce demographics, job roles, employee satisfaction, and other workforce patterns.

The dashboard helps identify employee attrition patterns across departments, education fields, age groups, gender, and job roles.

---

## 🎯 Business Objectives

The dashboard was designed to answer key HR-related questions:

- What is the overall employee attrition rate?
- Which departments have the highest number of employee attritions?
- How does attrition vary across different age groups?
- Which education fields have higher employee attrition?
- How does attrition differ by gender across age groups?
- How is employee satisfaction distributed across different job roles?
- What is the current active employee population?

## 📈 Dashboard Analysis

### 1. Attrition Count by Department

Analyzes employee attrition across HR, Research & Development, and Sales departments.

### 2. Employee Distribution by Age

Shows the distribution of employees across different age groups and helps understand workforce demographics.

### 3. Job Satisfaction Analysis

Shows job satisfaction levels across different job roles using satisfaction scores from 1 to 4.

### 4. Attrition Count by Education Field

Compares employee attrition across education fields such as Life Sciences, Medical, Marketing, Technical Degree, and Human Resources.

### 5. Attrition by Gender Across Age Groups

Analyzes the distribution of attrition by gender across different age groups.
